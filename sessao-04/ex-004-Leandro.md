Entreguem as respostas:
A diferença: Expliquem a diferença entre header e head, por palavras vossas.
 Resposta:
 - *head* define meta dados do Web site, ela é a parte
 invisível que guarda os dados para o navegador!

 - *header* é o topo da página que o utilizador vê, é a
 parte visível onde fica o logotipo e o título principal!


Article ou section? Imaginem um blog com vários posts. Cada post é um article ou uma section? E as partes dentro de cada post (introdução, corpo, conclusão)?
 Resposta: 
 - Cada post é um *article* 
   Porque o artigo de blog faz sentido por si só

 - Cada parte do post é um *section*
   a introdução, o desenvolvimento e a conclusão são *section*
   porque elas não fazem sentido sozinhas


Porquê semântica? Deem dois exemplos concretos de quem beneficia quando usamos elementos semânticos em vez de div para tudo.
 Resposta:
 porque a semântica dá significado ao código para que máquinas e programas entendam a estrutura do site!
  
  - Leitores de ecrã (Pessoas cegas)
  - Google (SEO)
